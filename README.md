# Temperature Summary CLI

Registra temperaturas, identifica os valores mínimo e máximo e calcula uma média simples entre eles.

Este é um projeto independente criado durante um curso de Visão Computacional.

## Tecnologias

- Python
- Biblioteca padrão do Python

## Como executar

~~~powershell
Nenhuma dependência externa.
python temperature_summary.py
~~~

## Arquivos

- **temperature_summary.py**: implementação do projeto.
- Arquivos de imagem/classificador necessários à demonstração.
